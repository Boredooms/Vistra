## 1. Purpose

Define every table, column, type, constraint, index, tenant ownership, retention, and deletion behavior.
This document is the contract that migrations must implement. Where prose and DDL disagree, the migration
must be corrected to match this document, or this document updated with an ADR.

## 2. Scope

Schema `public` on Supabase PostgreSQL 15+, with `pgvector` and full-text search. No other datastore holds
authoritative state (see doc 09 §8).

## 3. Conventions

- `id uuid primary key` is UUIDv7 generated by the application.
- `organization_id text not null references organizations(id) on delete cascade` on every tenant table.
- `created_at`, `updated_at timestamptz not null default now()`; `updated_at` via trigger
  `set_updated_at()`.
- Enums are PostgreSQL `create type … as enum` in `public`, or `text` + `check` when values will churn.
- Money: `cost_micros bigint` (USD × 1,000,000). Tokens: `integer`.
- 1:1 tables use the parent id as PK.
- All RLS: enabled + forced; policies in doc 19. Tables marked **global** (allowlisted, no
  `organization_id`): `organizations` (tenant root), `users`, `webhook_events`, `schema_migrations`.

Helper functions (created in migration 0001):

```sql
create extension if not exists pgcrypto;   -- gen_random_uuid fallback
create extension if not exists vector;      -- pgvector
create extension if not exists pg_trgm;     -- fuzzy title search
create domain email_address as citext;

create function set_updated_at() returns trigger language plpgsql as $$
begin new.updated_at = now(); return new; end $$;

create function current_org_id() returns text language sql stable as
$$ select nullif(auth.jwt() ->> 'org_id', '') $$;

create function current_user_id() returns text language sql stable as
$$ select nullif(auth.jwt() ->> 'sub', '') $$;

create function is_org_member(org text) returns boolean language sql stable security definer as $$
  select exists (select 1 from organization_members m
                 where m.organization_id = org and m.user_id = current_user_id()
                   and m.status = 'active');
$$;
```

## 4. Identity domain

```sql
create table organizations (              -- global tenant root
  id            text primary key,         -- Clerk org id: org_xxx
  name          text not null check (length(name) between 1 and 120),
  slug          text not null unique,
  image_url     text,
  plan          text not null default 'free' check (plan in ('free','starter','growth','enterprise')),
  data_region   text not null default 'us',
  settings      jsonb not null default '{}'::jsonb,
  retention     jsonb not null default '{}'::jsonb,  -- per-domain overrides (days)
  created_at    timestamptz not null default now(),
  updated_at    timestamptz not null default now(),
  deleted_at    timestamptz
);

create table users (                      -- global identity projection
  id            text primary key,         -- Clerk user id: user_xxx
  email         email_address,
  first_name    text,
  last_name     text,
  image_url     text,
  email_verified boolean not null default false,
  last_seen_at  timestamptz,
  created_at    timestamptz not null default now(),
  updated_at    timestamptz not null default now(),
  deleted_at    timestamptz
);
create index idx_users_email on users (email) where deleted_at is null;

create table organization_members (
  id              uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  user_id         text not null references users(id) on delete cascade,
  role            text not null check (role in ('owner','admin','developer','analyst','viewer')),
  status          text not null default 'active' check (status in ('active','invited','suspended')),
  clerk_membership_id text unique,
  invited_by      text references users(id) on delete set null,
  created_at      timestamptz not null default now(),
  updated_at      timestamptz not null default now(),
  unique (organization_id, user_id)
);
create index idx_members_org_role on organization_members (organization_id, role);
create index idx_members_user on organization_members (user_id);

create table webhook_events (             -- global: provider webhook inbox (Clerk etc.)
  id            text primary key,         -- provider event id (svix msg id)
  provider      text not null check (provider in ('clerk','stripe','github')),
  event_type    text not null,
  payload       jsonb not null,
  status        text not null default 'pending'
                check (status in ('pending','processed','skipped','failed')),
  attempts      integer not null default 0,
  error         text,
  received_at   timestamptz not null default now(),
  processed_at  timestamptz
);
create index idx_webhook_events_pending on webhook_events (received_at)
  where status in ('pending','failed');
```

**Retention:** identity rows deleted 30 days after `deleted_at`; `webhook_events` purged at 30 days.
**Deletion:** org cascade removes all tenant data via FKs; storage cleanup is asynchronous (doc 20).

```sql
create table projects (

create table application_domains (
  id              uuid primary key,

  unique (application_id, origin)
);

create table api_keys (
  id              uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  application_id  uuid references applications(id) on delete cascade,
  name            text not null,
  prefix          text not null,             -- vst_live_abc123 (display only)
  key_hash        text not null unique,      -- sha256 hex of full key
  scopes          text[] not null default '{}',
  mode            text not null default 'live' check (mode in ('test','live')),
  last_used_at    timestamptz,
  expires_at      timestamptz,
  revoked_at      timestamptz,
  rotated_from    uuid references api_keys(id) on delete set null,
  created_by      text references users(id) on delete set null,
  created_at      timestamptz not null default now()
);
create index idx_api_keys_app on api_keys (application_id) where revoked_at is null;
create index idx_api_keys_org on api_keys (organization_id, created_at desc);
```

**Never** return `key_hash`. Keys are shown once at creation; lookup is by hash with constant-time compare.

## 6. Sessions and conversations

```sql
create table application_sessions (        -- end-user session (auth + device)
  id              uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  application_id  uuid not null references applications(id) on delete cascade,
  end_user_ref    text not null,           -- opaque host-provided id
  end_user_meta   jsonb not null default '{}'::jsonb,
  origin          text,
  user_agent      text,
  ip_hash         text,
  status          text not null default 'active' check (status in ('active','revoked','expired')),
  started_at      timestamptz not null default now(),
  last_seen_at    timestamptz not null default now(),
  expires_at      timestamptz not null,
  revoked_at      timestamptz
);
create index idx_app_sessions_lookup on application_sessions
  (application_id, end_user_ref, started_at desc);
create index idx_app_sessions_org on application_sessions (organization_id, started_at desc);

create table sessions (                    -- conversation thread
  id                    uuid primary key,
  organization_id       text not null references organizations(id) on delete cascade,
  application_id        uuid not null references applications(id) on delete cascade,
  application_session_id uuid not null references application_sessions(id) on delete cascade,
  agent_version_id      uuid references agent_versions(id) on delete set null,
  title                 text,
  channel               text not null default 'widget'
                        check (channel in ('widget','api','studio','voice','workflow')),
  status                text not null default 'active'
                        check (status in ('active','idle','closed','error')),
  message_count         integer not null default 0,
  total_input_tokens    integer not null default 0,
  total_output_tokens   integer not null default 0,
  cost_micros           bigint not null default 0,
  metadata              jsonb not null default '{}'::jsonb,
  created_at            timestamptz not null default now(),
  updated_at            timestamptz not null default now(),
  ended_at              timestamptz
);
create index idx_sessions_org_time on sessions (organization_id, created_at desc);
create index idx_sessions_app_session on sessions (application_session_id);

create table session_messages (
  id              uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  session_id      uuid not null references sessions(id) on delete cascade,
  role            text not null check (role in ('user','assistant','system','tool')),
  content         jsonb not null,          -- parts: text, image_ref, element_ref, tool_result
  text_content    text,                    -- denormalized for search/export
  provider        text,
  model           text,
  prompt_version_id uuid references prompt_versions(id) on delete set null,
  input_tokens    integer,
  output_tokens   integer,
  latency_ms      integer,
  grounded        boolean,
  error_code      text,
  created_at      timestamptz not null default now()
);
create index idx_messages_session on session_messages (session_id, created_at);
create index idx_messages_org_time on session_messages (organization_id, created_at desc);

create table message_citations (
  id                 uuid primary key,
  organization_id    text not null references organizations(id) on delete cascade,
  message_id         uuid not null references session_messages(id) on delete cascade,
  chunk_id           uuid not null references document_chunks(id) on delete cascade,
  document_id        uuid not null references documents(id) on delete cascade,
  document_version_id uuid references document_versions(id) on delete set null,
  page_from          integer,
  page_to            integer,
  section            text,
  quote              text,
  score              numeric(6,5),
  start_offset       integer,
  end_offset         integer,
  created_at         timestamptz not null default now()
);
create index idx_citations_message on message_citations (message_id);

create table session_events (             -- ordered stream log (SSE replay)
  id              uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  session_id      uuid not null references sessions(id) on delete cascade,
  run_id          uuid,
  sequence        bigint not null,
  type            text not null,          -- see doc 25 §4
  payload         jsonb not null default '{}'::jsonb,
  created_at      timestamptz not null default now(),
  unique (session_id, sequence)
);
create index idx_session_events_run on session_events (run_id, sequence);
```

**Retention:** sessions/messages/events 90 days default (tenant-overridable 7–365); citations follow
messages. **Deletion:** hard delete in batches; `application_sessions` cascade removes sessions.

## 7. Agents, prompts, tools, policy, approvals

```sql
create table prompts (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  key text not null,                       -- e.g. orchestrator.plan
  description text,
  created_at timestamptz not null default now(),
  unique (organization_id, key)
);

create table prompt_versions (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  prompt_id uuid not null references prompts(id) on delete cascade,
  version integer not null,
  content text not null,
  variables jsonb not null default '[]'::jsonb,
  model_hint text,
  status text not null default 'draft' check (status in ('draft','active','archived')),
  created_by text references users(id) on delete set null,
  created_at timestamptz not null default now(),
  unique (prompt_id, version)
);

create table agents (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  application_id uuid not null references applications(id) on delete cascade,
  name text not null,
  slug text not null,
  kind text not null check (kind in
    ('orchestrator','vision','knowledge','guide','action','workflow','live')),
  description text,
  status text not null default 'draft' check (status in ('draft','published','paused','archived')),
  current_version_id uuid,
  created_by text references users(id) on delete set null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  deleted_at timestamptz,
  unique (application_id, slug)
);

create table agent_versions (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  agent_id uuid not null references agents(id) on delete cascade,
  version integer not null,
  system_prompt_version_id uuid references prompt_versions(id) on delete set null,
  model_config jsonb not null default '{}'::jsonb,   -- capability → model override
  retrieval_config jsonb not null default '{}'::jsonb,
  guide_config jsonb not null default '{}'::jsonb,
  tool_config jsonb not null default '{}'::jsonb,
  max_steps integer not null default 8 check (max_steps between 1 and 25),
  created_by text references users(id) on delete set null,
  created_at timestamptz not null default now(),
  published_at timestamptz,
  unique (agent_id, version)
);

create table tools (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  application_id uuid not null references applications(id) on delete cascade,
  name text not null check (name ~ '^[a-z][a-z0-9_]{1,63}$'),
  display_name text not null,
  description text not null,
  source text not null default 'http' check (source in ('http','mcp','builtin')),
  side_effect text not null check (side_effect in ('read','write','external')),
  status text not null default 'draft' check (status in ('draft','active','disabled')),
  current_version_id uuid,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  deleted_at timestamptz,
  unique (application_id, name)
);

create table tool_versions (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  tool_id uuid not null references tools(id) on delete cascade,
  version integer not null,
  args_schema jsonb not null,              -- JSON Schema (draft 2020-12)
  result_schema jsonb,
  http_config jsonb,                       -- {method,url_template,headers,body_template,timeout_ms}
  mcp_config jsonb,                        -- {server_id, tool_name}
  verification jsonb,                      -- {type:"read_back", method,url,expect}
  idempotency jsonb not null default '{"mode":"header","key":"Idempotency-Key"}'::jsonb,
  created_at timestamptz not null default now(),
  unique (tool_id, version)
);

create table agent_tools (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  agent_version_id uuid not null references agent_versions(id) on delete cascade,
  tool_version_id uuid not null references tool_versions(id) on delete cascade,
  enabled boolean not null default true,
  config jsonb not null default '{}'::jsonb,
  unique (agent_version_id, tool_version_id)
);

create table agent_policies (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  agent_id uuid not null references agents(id) on delete cascade,
  tool_id uuid references tools(id) on delete cascade,   -- null = all tools
  effect text not null check (effect in ('allow','deny','require_approval')),
  requires_approval boolean not null default false,
  conditions jsonb not null default '{}'::jsonb,         -- arg constraints, roles, limits
  priority integer not null default 100,
  created_by text references users(id) on delete set null,
  created_at timestamptz not null default now()
);
create index idx_agent_policies_agent on agent_policies (agent_id, priority);

create table tool_credentials (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  tool_id uuid references tools(id) on delete cascade,
  integration_id uuid references integrations(id) on delete cascade,
  name text not null,
  ciphertext bytea not null,                -- AES-GCM
  key_version integer not null default 1,
  created_at timestamptz not null default now(),
  rotated_at timestamptz,
  check (tool_id is not null or integration_id is not null)
);

create table tool_invocations (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  run_id uuid references agent_runs(id) on delete cascade,
  step_id uuid references agent_run_steps(id) on delete cascade,
  tool_id uuid not null references tools(id) on delete restrict,
  tool_version_id uuid not null references tool_versions(id) on delete restrict,
  idempotency_key text not null,
  args jsonb not null,
  status text not null default 'pending' check (status in
    ('pending','awaiting_approval','running','succeeded','failed','denied','expired')),
  attempt integer not null default 0,
  http_status integer,
  response jsonb,
  error_code text,
  error_detail text,
  verified boolean,
  verification jsonb,
  started_at timestamptz,
  finished_at timestamptz,
  duration_ms integer,
  created_at timestamptz not null default now(),
  unique (tool_version_id, idempotency_key)
);
create index idx_tool_invocations_run on tool_invocations (run_id);
create index idx_tool_invocations_org_time on tool_invocations (organization_id, created_at desc);

create table policy_decisions (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  run_id uuid references agent_runs(id) on delete cascade,
  step_id uuid references agent_run_steps(id) on delete set null,
  agent_version_id uuid references agent_versions(id) on delete set null,
  tool_id uuid references tools(id) on delete set null,
  decision text not null check (decision in ('allow','deny','require_approval')),
  reason_code text not null,
  matched_policy_id uuid references agent_policies(id) on delete set null,
  actor_type text not null,
  actor_id text,
  created_at timestamptz not null default now()
);
create index idx_policy_decisions_run on policy_decisions (run_id);

create table approvals (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  run_id uuid not null references agent_runs(id) on delete cascade,
  step_id uuid references agent_run_steps(id) on delete set null,
  tool_invocation_id uuid references tool_invocations(id) on delete cascade,
  args_snapshot jsonb not null,
  status text not null default 'pending'
    check (status in ('pending','granted','rejected','expired','cancelled')),
  approver_type text check (approver_type in ('end_user','user')),
  approver_id text,
  expires_at timestamptz not null,
  decided_at timestamptz,
  created_at timestamptz not null default now()
);
create index idx_approvals_pending on approvals (organization_id, created_at)
  where status = 'pending';
```

**Retention:** approvals 90 d, policy decisions 1 y, invocations 1 y (or 90 d for PII-bearing payloads),
`tool_credentials` until rotated/deleted.

## 8. Workflows and execution

```sql
create table workflows (
  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,

  name text not null, slug text not null,

    ('queued','planning','running','awaiting_approval','completed','failed','cancelled')),

  plan jsonb,
  current_step_index integer not null default 0,
  input_context jsonb not null default '{}'::jsonb,
  output jsonb,
  provider text, model text,
  fallback_used boolean not null default false,
  input_tokens integer not null default 0,
  output_tokens integer not null default 0,
  cost_micros bigint not null default 0,
  error_code text,

  finished_at timestamptz

  id uuid primary key,

  step_index integer not null,
  kind text not null check (kind in
    ('intent','plan','retrieval','vision','guide','policy','approval','tool','verify','respond')),
  status text not null default 'pending'
    check (status in ('pending','running','succeeded','failed','skipped')),
  input jsonb, output jsonb,
  provider text, model text,
  latency_ms integer,
  error_code text,
  started_at timestamptz,
  finished_at timestamptz,
  unique (run_id, step_index)
);
create index idx_run_steps_run on agent_run_steps (run_id, step_index);
```

```sql
create table knowledge_bases (

create table knowledge_collections (
  id uuid primary key,

  id uuid primary key,

);
-- Index created per KB index version, e.g.:
-- create index idx_embeddings_768_iv1 on embeddings
--   using hnsw (embedding vector_cosine_ops) with (m=16, ef_construction=64)

  id uuid primary key,
  organization_id text not null references organizations(id) on delete cascade,
  source_id uuid not null references knowledge_sources(id) on delete cascade,
  document_id uuid references documents(id) on delete set null,

    ('queued','fetching','parsing','chunking','embedding','indexing','ready','failed','cancelled')),
  stage text,
  attempt integer not null default 0,
  max_attempts integer not null default 3,
  run_after timestamptz not null default now(),
  locked_by text, locked_at timestamptz, heartbeat_at timestamptz,
  error_code text, error_detail text,
  stats jsonb not null default '{}'::jsonb,  -- pages, chunks, tokens, bytes
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  finished_at timestamptz
);
create index idx_jobs_claimable on ingestion_jobs (run_after, created_at)
  where status in ('queued','fetching','parsing','chunking','embedding','indexing');
```

**Dimension note:** `vector(768)` is the default. A KB may set `embedding_dim = 1536` or `3072`; the
migration that changes a KB dimension creates a parallel embeddings table or a new index version with the
matching column type (documented procedure in doc 38 §9). Never mix dimensions in one index.

**Retention:** chunks/embeddings live until document or source deletion; ingestion jobs 30 days after
`finished_at`.

## 12. Triggers, functions, jobs

| Object | Purpose |
|---|---|
| `set_updated_at()` trigger on mutable tables | Keeps `updated_at` truthful |
| `check_member_org_consistency()` on child inserts | Asserts denormalized `organization_id` matches parent |
| `search_documents(q, org, collections, k)` | Hybrid retrieval function (doc 38) |
| `pg_cron` daily jobs | Retention sweep, rollup, partition maintenance |
| `pg_cron` job reaper | Reset jobs whose `heartbeat_at < now() - interval '5 min'` |

## 13. Migration ordering (first 10)

1. `0001_extensions_and_helpers` — extensions, domains, functions, `updated_at` trigger.
2. `0002_identity` — organizations, users, members, webhook_events.
3. `0003_tenancy` — projects, applications, domains, api_keys.
4. `0004_prompts_agents` — prompts, agent tables.
5. `0005_integrations_tools` — integrations, tools, credentials, mcp_servers.
6. `0006_execution` — agent_runs, steps, invocations, policy, approvals, workflows.
7. `0007_knowledge` — KBs, collections, sources, files, documents, versions, chunks, embeddings, jobs.
8. `0008_conversations` — application_sessions, sessions, messages, citations, events.
9. `0009_visual_guides` — snapshots, guide flows/steps.
10. `0010_ops` — audit, usage, outbox, errors, evaluations, feedback, webhooks.

Each migration also creates its RLS policies (doc 19) and indexes in the same file.

## 14. Acceptance criteria

- [ ] A clean database migrates to this schema with zero errors and zero drift.
- [ ] Every column here exists; every column in the DB appears here.
- [ ] Every FK has a declared `ON DELETE`; no `NO ACTION` defaults left implicit.
- [ ] Every index references a query pattern in this or a related document.
- [ ] Cross-tenant denial tests exist for every table with `organization_id`.
- [ ] Generated TypeScript/Python types match the migrated schema (introspection test).
